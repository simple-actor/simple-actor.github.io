Web scrapers I build, run and fix in production.

I build scrapers, publish them on Apify, and keep them running when the sites change underneath them. Each post here takes one real problem, such as every dentist in a city with an email address, and solves it with a real run: the input, the output, what it cost, and where it stops working.

The code for every post is on GitHub.
